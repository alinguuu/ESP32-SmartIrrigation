## 📦 Bill of Materials (BOM)

### Controller & Computing
* **ESP32-S3-DevKitC-1-N8R2** (8MB Flash / 2MB PSRAM)
* **Banana Pi Pro A20** (Network server/broker, housed in a custom 3D case)

### Power Management
* **1x XL4016 Buck Converter:** Main 12V DC power rail for solenoid valves.
* **1x XL6009 Buck-Boost:** 9V DC output for auxiliary camera hardware.
* **1x XL6009 Buck-Boost:** 5V DC output for ESP32-S3 board and relay logic.
* **1x XL6009 Buck-Boost:** 3.3V DC output dedicated to sensor logic.

### Actuators & Sensors
* **2x 4-Channel Relay Modules** (8 solenoid valves, switching 12V DC)
* **2x IRFZ44N MOSFETs** (Enclosure LED and secondary high-power outputs)
* **4x Digital Soil Moisture Sensors**
* **1x DHT11 Sensor** (Temperature & Humidity)
* **1x LDR Light Sensor Module** (Digital Output via LM393)
* **1x Physical Panel Pushbutton**
* **1x WS2812B / WLED Strip** (Remote network-connected visual indicator)

## 💻 Step-by-Step Firmware Setup & Flashing

### Step 1: Environment Preparation
1. Install **VS Code** with the **PlatformIO** extension (recommended) or **Arduino IDE 2.x**.
2. If using Arduino IDE, install the **ESP32 Board Package** via Board Manager (`https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`).
3. Select board target: `ESP32S3 Dev Module`.

### Step 2: Library Dependencies
Ensure the following libraries are installed before compilation:
* `WiFi.h` & `WebServer.h` (ESP32 Core)
* `HTTPClient.h` (WLED API Requests)
* `DHT sensor library` by Adafruit
* `Preferences.h` & `LittleFS.h` (NVS Storage)
* `mbedtls/sha1.h` (Hardware TOTP Cryptography)

### Step 3: Understanding `index.h`
The entire web interface (HTML, CSS, JavaScript) is placed inside `index.h` using standard C++ `PROGMEM` syntax:
* **Memory Optimization:** Stored directly in ESP32-S3 Flash memory, keeping RAM free for real-time sensor cycles.
* **Modularity:** Keeps core logic in `main.ino` clean and separate from web design code.

### Step 4: Configuring Parameters & Flashing
1. Open `main.ino` and update Wi-Fi credentials (`ssid`, `password`).
2. Set your custom **TOTP Secret Key** (Base32 string).
3. Connect the ESP32-S3 via USB-C (ensure correct COM port selected).
4. Set partition scheme to **8MB with Spiffs/LittleFS** if prompted.
5. Click **Upload / Flash** and monitor output via Serial Monitor at **115200 baud**.

## 🔒 TOTP 2FA Setup

1. Locate the Base32 Secret Key defined in `main.ino`.
2. Open your 2FA app (**Google Authenticator**, **Authy**, or **1Password**).
3. Choose **"Enter a setup key"** / **"Manual entry"** and paste the key.
4. Name the entry (e.g., *Irrigation System*).
5. Any manual command sent via the Web UI or Mobile App will require the active 6-digit TOTP code generated by your app.

## 📲 Mobile App (APK) Setup & Domain Editing

The pre-compiled Android APK targets the default domain: `sulama.utkudsoz.com.tr`.

If you are using a self-hosted server or direct IP, update the APK using **APK Editor**:

1. Download **APK Editor** (Android) or **APK Easy Tool** (Windows).
2. Load the project's APK file.
3. Choose **Full Edit** / **Common Edit**.
4. Search for `sulama.utkudsoz.com.tr` in `assets/` or `res/values/strings.xml`.
5. Replace it with your custom IP or domain (e.g., `192.168.1.100`).
6. Click **Build**, sign the application with a test key, and install it on your smartphone.

## 🖨️ 3D Enclosure Assembly & Field Deployment

### Printing Guidelines
* **Material:** PETG or ASA (UV and weather resistant for outdoor environments).
* **Layer Height:** `0.2mm`or `0.12mm`| **Infill:** `20%-30% Gyroid`.

### Assembly Steps
1. **SBC Housing:** Mount Banana Pi Pro A20 in `bananapi-case-bottom-fan.stl` and secure a 5V fan on `bananapi-case-top.stl`.
2. **Soil Probe Protection:** Insert soil probes into `soil-sensor-casing.stl` and apply silicone sealant around `soil-sensor-cap.stl`.
3. **Cable Management:** Route 12V valve wiring through `cable-junction-box-large.stl` using green terminal blocks to prevent short circuits.
4. **Main Chassis:** Secure relay modules and power converters to `main-mounting-plate.stl` inside the main electrical box.
