# Security Policy

## Supported Versions

We active release security patches for the following versions of **ESP32-SmartIrrigation**:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0   | :white_check_mark: |

## Reporting a Vulnerability

Security is a top priority for this project, especially concerning authentication mechanisms (TOTP 2FA), web interface integrity, and local network control.

If you discover a security vulnerability, please **DO NOT** open a public GitHub issue.

### How to Report:
* **Private Vulnerability Reporting:** Please use the **[Private Vulnerability Reporting](https://github.com/alinguuu/ESP32-SmartIrrigation/security/advisories/new)** feature under the **Security** tab of this repository.
* **Direct Contact:** Alternatively, you can reach out directly via my personal website/contact page at [utkudsoz.com.tr](https://utkudsoz.com.tr).

### What to Include:
* A description of the vulnerability and its potential impact.
* Steps to reproduce the issue (including hardware/firmware setup details if applicable).
* Any potential fix or mitigation idea.

We will acknowledge your report within 48 hours and work on a fix promptly. Thank you for helping keep this project secure!
